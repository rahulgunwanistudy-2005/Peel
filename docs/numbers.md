## Banana100 chains

Images were read at reduced size (long side 1280, evaluated at 1024). Only chains at the start of a parquet row group can be fetched cheaply, which is why these chains were chosen; see eval/BANANA100_NOTES.md.

**Edit chain: one object added per step** (n = 1). Each step asks for one more apple. The raw chain feeds every output back into the editor; the peeled chain keeps each new apple and anchors everything else to step 0.
