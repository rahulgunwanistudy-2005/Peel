# Peel

Keep the edit you asked an AI image editor for. Undo everything else it changed.

This Space runs the Peel API (FastAPI, CPU only) and serves the web app at `/`.
Interactive API docs are at `/docs`. Source: https://github.com/rahulgunwanistudy-2005/Peel

Optional secret: `GEMINI_API_KEY` enables "Edit with Nano Banana". Nothing else depends on it.
